A compact chess engine in 4 KB of Python: 0x88 board, negamax with alpha-beta, transposition table, quiescence search, and piece-square evaluation. Fixed 100,000-node search per move — fully deterministic, no model calls.

## Run it

```sh
MAKEFUN_ENV_URL=<env-url> python3 main.py
```
